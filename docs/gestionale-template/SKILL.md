# Gestionale Template Skill

Use the Perfect Line codebase as a reusable foundation for subscription-based gyms, studios and sports associations.

## Tenant configuration
Brand name, legal name, logo, palette, address, contacts, plans, prices, expiry windows and notification channels.

## Core modules
Dashboard, Customers, Memberships, Payments, Expirations, Settings, Audit Log.

## Design rule
A new customer should be created by tenant configuration and seed data, not by copying or changing business logic.
